# 人工智能和计算机开发基础

写给想真正理解 AI 与软件如何运转的读者。不预设背景，也不居高临下：不教写代码，也不教训模型，只求读完能判断：一条技术路线解决什么问题、
为什么有效、什么时候会失效。

全书两部分：

- **人工智能基础**：从神经元讲到智能体，含三条大模型架构路线的定性对照。
- **计算机开发基础**：从"程序是什么"讲到许可证政治，含可复现性与声明式系统。

## 读这本书

| 只想搞懂 AI | 只想搞懂开发工具 | 想建立完整图景 |
|:--|:--|:--|
| 第 1 部分 | 第 2 部分（2.1 起） | 按顺序 |

每节结构一致：一句话直觉、生活类比、示意图、它解决什么问题、**它的天然短板**、小结与自检。
公式统一收在节末"数学注解"里，跳过不影响阅读。
